# Security Policy

## Supported version

Security fixes target the current `main` branch and the production deployment at
[kreativauto.com](https://kreativauto.com/).

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, leaked credential, privacy
problem, or analytics-data exposure.

Send a concise report to `info@kreativauto.com` with:

- the affected URL, file, or commit;
- steps to reproduce the issue;
- the likely impact;
- any suggested mitigation;
- a safe way to contact you for follow-up.

Do not access visitor data, disrupt the production site, perform social engineering,
or test third-party services without authorization. The project will acknowledge a
valid report when practical and will coordinate disclosure after a fix is available.
