# Kreativ Auto

Static Astro site for `kreativauto.com`, built for automotive SEO content, affiliate comparison pages, and future tools.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages

This project is prepared for deployment with GitHub Pages using GitHub Actions.

Deployment source:

- GitHub Actions workflow: `.github/workflows/deploy.yml`
- Production branch: `main`

### Environment variables

Optional public environment variables:

- `PUBLIC_GA_MEASUREMENT_ID`
- `PUBLIC_GOOGLE_SITE_VERIFICATION`

You can copy values from `.env.example`.

### Custom domain

Use `kreativauto.com` as the custom domain in the repository's GitHub Pages settings.

Recommended GitHub Pages setup:

1. Go to `Settings -> Pages`
2. Set `Source` to `GitHub Actions`
3. In `Custom domain`, enter `kreativauto.com`
4. Enable `Enforce HTTPS` after the certificate is issued

### DNS notes

- For apex `kreativauto.com`, GitHub documents these `A` records:
  - `185.199.108.153`
  - `185.199.109.153`
  - `185.199.110.153`
  - `185.199.111.153`
- If you also want `www.kreativauto.com`, add a `CNAME` record pointing `www` to `aolaru.github.io`

### Notes

- The site is fully static.
- Sitemap output is generated automatically during build.
- `robots.txt` is generated by Astro.
- `public/.nojekyll` is included so GitHub Pages serves Astro's `_astro` assets correctly.
